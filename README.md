# NEXUS AI Frontend

Responsive React + Vite dashboard prototype for an AI Market Intelligence and Learning platform.

## Features
- Responsive mobile and desktop layout
- Overview, Market Analysis, Learning Center, History and Settings pages
- Sample chart and market watchlist
- Demo analysis interaction and local history
- Explicit simulation-only interface; no trading or brokerage integration

## Requirements
- Node.js 18+ and npm
- Internet connection for first dependency installation

## Run
```bash
npm install
npm run dev -- --host 0.0.0.0
```
Open the local URL printed by Vite. On the same phone, use the `localhost` URL. On another device on the same Wi-Fi, use the computer/phone LAN IP and Vite port.

## Important
All market values and analysis examples are mock/demo data. This frontend does not connect to a live market data provider, does not provide financial advice, and cannot place real trades.
